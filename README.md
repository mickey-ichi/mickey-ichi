# Hi, I'm Hung (mickey-ichi) 👋

**Full-stack TypeScript developer in Hanoi, building the bridges between AI agents and the tools real teams use.**

AI agents like Claude, Codex and Cursor can reason through almost anything — but the work itself lives in ticket
trackers, spreadsheets and customer portals they can't reach. I build small, dependable open-source tools (MCP servers,
CLIs and agent skills) that close that gap, safely.

## 🧭 How I build for the AI era

- **Agents propose, humans approve** — every write is a preview until someone says yes
- **Secrets stay local** — keys never pass through the chat, logs or prompts
- **Content is data, not instructions** — tickets and cells can't steer the agent
- **Small and auditable** — zero runtime dependencies where possible, MIT licensed
- **Works where you work** — CLI, MCP and skills for Claude Code, Codex and Cursor, on macOS, Linux and Windows
- **Multilingual by default** — docs in English, Tiếng Việt and 日本語 for teams working across borders
